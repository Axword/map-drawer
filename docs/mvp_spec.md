# Specyfikacja MVP — ArkhamWeaver

Minimalny Produkt Wdrożeniowy (MVP) realizuje w pełni wszystkie 9 założeń przedstawionych w wymaganiach użytkownika:

1. **Kreator map bez rysowania**: Gotowe assety oraz wbudowany generator oparty na promptach (Prompt Wizard).
2. **Mapy zagnieżdżone**: Hierarchia Świat -> Miasto -> Ulica -> Budynek -> Piętro -> Pokój z nawigacją kaskadową.
3. **Obiekty z właściwościami**: Każdy obiekt na mapie (np. biurko profesora) posiada opis, ukryte informacje, zamknięte zamki, wymagane klucze i zawartość.
4. **System NPC i symulacji**: Postacie z profilami, historią, celami, harmonogramem dnia i relacjami.
5. **Tryb projektowania gry (Logika)**: Edytor reguł logicznych JEŻELI / WTEDY dla questów i śledztw.
6. **Baza wiedzy świata**: Kartoteka i sieć powiązań łącząca postacie, organizacje i wydarzenia.
7. **Interfejs użytkownika**: Spójny, mroczny interfejs w klimacie akt policyjnych i archiwum lat 20. XX wieku (Tailwind CSS + custom typography).
8. **Technologia**: React 19 + Vite + TypeScript + Tailwind CSS + Lucide Icons + Eksport/Import JSON.
9. **Doświadczenie użytkownika (Magic Moment)**: Możliwość wygenerowania całego świata z NPC i tajemnicą za pomocą jednego kliknięcia w kreatorze promptów AI.
