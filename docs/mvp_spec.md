# Specyfikacja MVP — ArkhamWeaver

Minimalny Produkt Wdrożeniowy (MVP) realizuje w pełni wszystkie 9 założeń przedstawionych w wymaganiach użytkownika:

1. **Kreator map bez rysowania**: Gotowe assety oraz wbudowany generator oparty na promptach (np. "Willa w Arkham 1924").
2. **Mapy zagnieżdżone**: Hierarchia Świat -> Miasto -> Budynek -> Piętro -> Pokój z nawigacją okruszkową (Breadcrumbs).
3. **Obiekty z właściwościami**: Każdy obiekt (np. biurko profesora) posiada opis, właściciela, zamknięte szuflady, ukryte listy, klucze i ślady krwi.
4. **System NPC i symulacji**: Postacie z profilami, relacjami, ekwipunkiem i harmonogramem dnia (np. Profesor Smith o 23:00 w tajnej piwnicy).
5. **Tryb projektowania gry (Logika)**: Prosty edytor reguł logicznych JEŻELI / WTEDY (np. klucz + książka = otwarcie tajnego przejścia).
6. **Baza wiedzy świata**: Graf relacji w stylu Obsidian łączący postacie, organizacje i wydarzenia.
7. **Interfejs użytkownika**: Spójny, mroczny, responsywny interfejs webowy w klimacie lat 20. XX wieku.
8. **Technologia**: React + Vite + TypeScript + Tailwind CSS + Lucide Icons + LocalStorage + Moduł JSON Import/Export.
9. **Doświadczenie użytkownika (Magic Moment)**: Możliwość wygenerowania całego miasta z NPC i tajemnicą za pomocą jednego kliknięcia w kreatorze promptów.
